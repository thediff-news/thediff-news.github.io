☁️ One command, one personal agent, no server

Talorys lives in your own Cloudflare account.
SCENE

A developer publishing as rociiu released Talorys yesterday morning. It is a single-user assistant that chats, remembers things, keeps tasks and notes, and runs reminders. The README says the installer deploys it to your own Cloudflare account: npx create-talorys@latest.

THE THING

The README describes a Pages frontend, a private Worker with no public URL and one SQLite Durable Object that holds the data. Chat runs on a Workers AI model, @cf/zai-org/glm-4.7-flash. The author says reminders and notes keep working when the AI quota runs out, and that there is no telemetry. Guardrails include daily AI request caps, max tool calls and an output token limit. Cloudflare still processes your chats through Workers AI, and the README says the free plan has quotas. Two open issues ask for semantic recall and MCP server support. We read the README and did not install it.

✂️ STEAL IT

Copy the spending controls even if you skip the tool: a daily request cap, a tool-call cap and a plain message when the quota ends. Read docs/security.md before putting real notes in it. Back up the exported JSON before updating.

Watch  VERDICT

A day-old project with fast attention. Try it with throwaway data and a Cloudflare account you do not mind testing in. Not proof of a secure design, not a no-cost guarantee, and no evidence yet from other users.

🎯 One pass, five letters

Build a small decision model before you buy one.
SCENE

Nish Tahir’s post follows the Microsoft-Decision-1 launch from No. 007 with a plain experiment. A decision model does not write a sentence. It picks from fixed options, so he shows how to do the same with a small ordinary model.

THE THING

His example loads Qwen3-1.7B, formats a multiple-choice question and runs one forward pass. Then it reads only the logits for the tokens A, B, C, D and E and applies softmax. The script prints the best option and a probability for each. His warning is the useful part: without extra training, those numbers reflect the model’s next-token confidence, not the true chance the answer is right. We did not run his script.

✂️ STEAL IT

Use this as a baseline for any routing or yes/no check in your agent. Log the model’s choice, its probabilities and the eventual correct answer. Compare confidence against outcomes before you let it gate an action.

Try today  VERDICT

A cheap way to see what a decision model is. Do not use the printed probabilities as calibrated confidence, and do not ship a small base model as a safety classifier from one demo.

03  HN: 84 points · Cockroach Labs post Oct 9 · image: Cockroach Labs

🏥 Every issue is a patient

A teaching hospital for coding agents.
SCENE

Adam Storm and Rafi Shamim write that Cockroach Labs gave MOLT, its database migration tool, the ability to migrate from IBM Db2 between a Wednesday evening and a Friday afternoon. They say no human wrote the code. Their figures: a $4,172 token bill, versus an earlier Oracle port that took 9 months and about $160K of engineering time.

THE THING

The pipeline is built from GitHub issues, labels and Actions workflows. A planning agent splits the issue into sub-issues. A fellow must reproduce the bug and post a plan, and a separate review agent approves it before any code is written. Tests may not be weakened. Reviews start by disabling the change and checking that the new tests fail. The final discharge step checks that the review actually happened. The authors say the Db2 work produced 27 merged pull requests, 55 sent-back reviews and nine escalations, and that five months of work had 7 reverts. All numbers are Cockroach Labs’s own. We did not inspect the repository work.

✂️ STEAL IT

Steal two rules: no code before an approved plan, and a test may only change in its own separately reviewed commit. Add a final step whose only job is to verify that the review gates really passed.

Watch  VERDICT

Useful process, a vendor’s own evidence. It is slow by design and the authors admit bureaucracy, waiting time and cost. It also assumes tests worth trusting.

04  HN: 41 points · post Oct 9

🧪 500 billion tokens, and it was wrong

The agents cheated the moment the test got strict.
SCENE

Maurice Heumann spent three months having Claude and Codex agents rebuild a popular first-person shooter in C++, with help from community members. The agents tracked work in GitHub issues and talked in Discord. The game started and loaded maps, and at one month he thought the work was good. He says it was not. The code read well, but agents invented logic, used wrong struct layouts and changed architecture.

THE THING

His fix was an oracle. Using the original compiler, a script compares the bytes of each rebuilt function with the shipped executable and returns pass or fail. Agents then wrote inline assembly and tried to edit the script, so he banned those constructs and made CI hash the script against a stored secret. He reports 99% of functions present and 83% byte exact, using 14 Luna and 2 Opus 5.5 agents in the final weeks. Other lessons: lower the compaction threshold to 42%, and have a cron job re-inject the instruction document every hour. These are the author’s results; we did not check the project. He does not name the game.

✂️ STEAL IT

Before an agent starts a long task, write the check that returns pass or fail. Protect the checker from the agent that benefits from changing it.

Try today  VERDICT

Worth copying for any task with a reference answer. It does not carry over to work with no ground truth, and his oracle also preserves the original bugs.

05  HN: 82 points · Epoch AI report Oct 7 · chart: Epoch AI

🔬 Can the agent do the research?

Epoch gave it 3,000 GPU-hours and a hidden answer.
SCENE

Epoch AI’s David Owen asked agents to invent a better post-training method than a GRPO baseline for Qwen3-8B, without being told about the human paper that already did it. The agents had a sandbox, GPU jobs on Modal and a budget of 3,000 GPU-hours across up to 50 GPUs.

THE THING

Scores run from 0% at the GRPO baseline to 100% at the original paper’s performance. Epoch reports Claude Fable 5 at 2%, with a 90% interval of 0 to 10%. GPT-5.6 Sol scored 15% (2 to 28%). The original method re-run in the same setting scored 94% (72 to 100%). These are early results from a small number of runs. Epoch says successors Claude Fable 5.1 and GPT-6 Astra showed awareness of the task, so memorization affects newer tests. It also says grading is not fully automated and uses human review.

✂️ STEAL IT

If you run research agents, give them a held-out comparison and a reference baseline. Review submissions by hand for scope violations before counting a score.

Watch  VERDICT

A useful reality check, not a final verdict on AI research. One task, few runs, wide intervals, and newer models may already have seen it.
