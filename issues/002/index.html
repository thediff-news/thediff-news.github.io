Hard budget caps, for the agent that never sleeps 🐷

Simon Willison asks every cloud to ship them by default
SCENE

Simon Willison, on Oct 3: nobody wants to wake up to an email sent at midnight warning about a budget limit, to find that a rogue service ate several hundred or several thousand more dollars while they slept. Coding agents make it cheap to spin up code that calls paid APIs, he writes, and he has heard from people who refuse to use AWS for personal projects for fear of a runaway bill, and from people who ended up seriously burned. The post hit 562 points on Hacker News.

THE THING

Two providers have shipped something. AWS announced project spend limits on Sep 16: at the limit, the project is paused for the month. Its docs say a Paid Plan is required and that the new experience is rolling out to a limited number of customers. Google Cloud's Spend Caps pause new usage of eligible services in a project once estimated cost passes the budget. Its docs call it Pre-GA and list four services: Gemini API, Gemini Enterprise Agent Platform (formerly Vertex AI), Cloud Run and Cloud Run functions. They also say caps do not pause fixed usage on persistent resources like compute and storage, and you lift a cap by hand. An HN commenter called Google's caps fake because of the short list; the docs confirm the short list, so "narrow" is fair, "fake" is his word.

✂️ STEAL IT

Open the billing console of the one provider your agent can spend on and set a hard cap on the project it uses. On Google, check whether your service is one of the four. Where there is no hard cap, create a separate project or key with a low prepaid balance for agent work.

Try today  VERDICT

Ten minutes. It fails where your spend is not on an eligible service, on AWS where you are not in the limited rollout, and on anything that bills for storage or running instances, which a cap does not stop.

A 125B model on a gaming PC 🎮

Strata, and the one line in its README to read before you paste
SCENE

On Hacker News, snehesht reported 124 tokens per second on an RTX 4090 and prettyblocks said it flies on a 3090. Those are their numbers, not ours. The README's own figures are 94 tokens per second on an RTX 5070 and 60 on an AMD RX 9070 XT, at a 2-bit quantization.

THE THING

Niko1221/Strata, MIT, created Sep 24, 11,352 stars and 304 open issues when we looked. Per its README it runs a 125B-parameter Qwen3.8-Flash-Next model on a consumer gaming PC. The thread has 195 comments. We did not run it: it needs a GPU we do not have. Star counts move fast on a launch like this and we did not check how they grew.

✂️ STEAL IT

The README suggests pasting a prompt into your agent that says to set Strata up on your PC by following docs/AI_SETUP.md. A commenter, deadbunny, flagged that as a prompt-to-install risk. Before you paste anything like it, open the file it points to and read what it will run.

Watch  VERDICT

The speeds are the author's and commenters' reports on three GPUs, and nobody has shown that quality holds at 2-bit for real coding. It fails if your agent needs long context or tool calling reliability, which the README numbers do not cover.

Turn off Apple Intelligence, get the disk back 🍏

RemoveMacAI, and the curl | bash argument it started
SCENE

On Hacker News, Noaidi wrote that Apple Intelligence, turned off, still takes about four gigs on an iPhone: it vanished and came back. On the top of the thread, arialdomartini replied to the installer with a link to nocurlbash.com. Meanwhile nailer noted the project does curl | bash "properly", with a checksum and build attestation.

THE THING

omlahore/RemoveMacAI, MIT, created Sep 29, 566 stars. Per the README, macOS 27 no longer has a single switch for Apple Intelligence and its models stay on disk after the features are off. The tool turns the features off, removes the models and blocks re-download. The list includes Xcode predictive code completion. It installs a configuration profile that macOS makes you approve, and has status, off --dry-run and revert. The README gives no gigabyte figure, so we cannot tell you how much space you get back. We did not run it.

✂️ STEAL IT

If you are on macOS 27, run removemacai status only after reading install.sh, then off --dry-run to see the changes before applying anything. The README says gh attestation verify checks that a download came from the repo's source.

Watch  VERDICT

A real complaint with a careful installer. It fails if you rely on Xcode's predictive completion or Siri, and it is a third-party script that changes a system profile on your machine. Revert is documented, we did not test it.

Agents don't need memory, they need documentation 📓

a year of a plain folder, now a plugin
SCENE

Kevin Liao says that over a year ago he started telling his agent to write everything down in an internal/ folder: specs, plans, indexes. He had it read the right documents before work and update them after. By his own account that grew into a plugin called Operator Memory. His Oct 3 essay argues every memory plugin is the same thing underneath: snippets in a vector database, the top five injected into each prompt.

THE THING

aerovato/operator-memory, BSD-3-Clause, 268 stars. Per the README, the agent keeps a Markdown "brain" of instructions, specs, research and indexes, consults it before work and updates it after, with no vector database or embeddings. It lists Claude Code and Codex as fully supported. The claims that it works better than RAG memory are the author's, and we did not test them.

✂️ STEAL IT

You do not need the plugin. Make a docs/ folder, add an index.md, and put two lines in CLAUDE.md: read docs/index.md before starting, update the relevant doc after finishing. Run it for a week and see how many corrections you stop repeating.

Try today  VERDICT

Two lines, no install, files you can read and commit. It fails when the docs go stale faster than the agent updates them, which is the author's own point about memory snippets.

Faster clean Rust builds, from patching the compiler 🦀

headstart, and why it is not for production yet
SCENE

You change a Rust dependency in CI and wait for a clean build. PowderworksCode's headstart patches rustc (-Zearly-metadata) and cargo (-Zheadstart) so crates can start compiling before their dependencies finish.

THE THING

PowderworksCode/headstart: 40 stars, created Sep 27, pushed Oct 4, and the repo shows no license. Per the README, clean builds of 13 projects ran up to 54% faster for cargo check and 42% for cargo build on 16 cores; OpenAI's codex-rs built 37% faster; the gain shrinks on 4 cores. Those are the author's numbers, we did not reproduce them. The README says the goal is upstream pull requests.

✂️ STEAL IT

Do not install a patched compiler. Check your own clean-build time on a many-core runner: if cargo is mostly waiting on a long dependency chain, this is the idea to watch land upstream.

Watch  VERDICT

Big claimed numbers on a patched toolchain with no license. It fails on small machines (gains shrink at 4 cores) and until the changes are in stable Rust.

A package manager written entirely by Claude Code 📦

jpm, with install scripts blocked until you approve
SCENE

JT Turner, an engineer of 27 years, says on Hacker News he built jpm at first to see if it was possible. By his account it worked within a few hours, then took another five days of the agent looping on popular packages and hardening it on Windows, Mac and Linux. The jpm site says Claude Code on Opus 5.5 wrote every line, its own TLS included, and that his condition was to test it as if nobody trusted it.

THE THING

getjpm.sh, a Rust package manager in one binary of about 2 MB. Per its page, on GitHub CI a cold nuxt install (591 packages) took 1.22 s against 1.28 s for bun and 18.54 s for npm, and jpm is fastest in 9 of 12 cells. Those are the author's benchmarks. The security defaults are the interesting part: dependency install scripts do not run until jpm approve, versions less than a day old are not picked, and a project's own .npmrc cannot lower TLS checks. It imports your existing lockfile and leaves the old one alone. We did not run it.

✂️ STEAL IT

Even if you never switch, copy two settings into your own package manager: ignore install scripts by default, and set a minimum release age of a day. The page says its own approval step is not a sandbox: a script you approve runs as you.

Watch  VERDICT

A fast, strict idea from a one-person project with 6 HN points and no track record. It fails on trust: its TLS and crypto are home-grown, and we only have the author's tests and benchmarks.

Did a 50 year old military secret just solve agent prompt injection?
Fireship · 5:03 · 828,490 views when we looked · uploaded Sep 30 · thumbnail from YouTube

We did not watch it all. We read the description and the project it points to. The video covers OpenAPPA (archestra-ai/OpenAPPA, MIT, 1,405 stars, created Aug 18, marked preview and RFC). Per its README it sits between an agent and its tools and checks, before every call, whether this data may go to this destination, using a declarative TOML policy and no model in the decision.
