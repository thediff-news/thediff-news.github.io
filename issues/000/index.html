Doom is now a Claude Code mod 👹

the most-liked thing about mods so far is a deathmatch
SCENE

Claude is thinking. You have two minutes. So you play Doom against everyone else who is also waiting on their Claude. @jarrodwatts posted this on Oct 2 with the line "Every other player in the match is a person waiting for their Claude to finish." It has 7,398 likes and about 427K views on X. Hours later @alexchristou_ copied the idea with a Modern Warfare 2 quick-scoping lobby: 3,900 likes, about 262K views.

THE THING

jarrodwatts/intermission, MIT, 79 stars, a Claude Code mod (per its README: Odamex plus Freedoom, about a 20 MB download). Mods are plugins whose code runs inside the session. Per Claude's own getting-started post (Oct 1, by Addy Osmani): they "can rewrite or replace what Claude Code does, and can even draw custom UI." Needs Claude Code 2.1.287 or later.

✂️ STEAL IT

Forget the game. The pattern is the point: a mod can take over the dead time of a run. Ask yourself what you would put there. A flashcard, a diff review, a stretch timer.

Watch  VERDICT

Fun and harmless-looking, and it shows what the mod API can do. It fails on a work laptop that blocks game servers. We have not run it.

Claude Code now tells you what you missed 📣

the official "You should know" plugin, one command
SCENE

@ClaudeDevs announced a new built-in plugin on Oct 2: "You should know". Per the post it "scans Claude's output for important information you might miss to help keep you in the loop." It got 13,029 likes and about 1.1M views, by far the biggest mods post. A second post from @trq212 calls it "a great example of the kind of things mods enable" (1,756 likes).

THE THING

Enable command from the announcement: /plugin enable cc-plugin-you-should-know@builtin. @lydiahallie's walkthrough (1,886 likes) says mods are "plugins with a few special functions that let your code run inside Claude Code, like middleware."

✂️ STEAL IT

Turn it on for one real session. Then count how many times it surfaced something you would have missed. If it is zero, turn it off. That is your answer.

Try today  VERDICT

One command, official, easy to undo. It fails if you already read every line Claude writes. We have not run it, so we can't say how noisy it is.

Your session hits 600K tokens and hands itself over 🫙

a mod that writes the handoff and runs /clear for you
SCENE

You are three hours into a long Claude Code session. The context is nearly full and you are about to lose the thread. cablate's mod watches the context. When it passes 600K tokens, or 80% of the window if lower, it writes a handoff summary, runs /clear and submits the summary to a fresh conversation. If you go idle, it keeps the prompt cache warm for up to about 4 hours.

THE THING

cablate/ctx-handoff-mod. The README says it is experimental, built on Claude Code's early-access function-hooks API, and that its 9 plugin tests pass. It also says what is not yet seen: a full real session reaching 600K, and whether the idle refresh keeps a 1-hour cache alive. Its messages are in Traditional Chinese.

✂️ STEAL IT

Even if you skip the mod, steal the rule: write the handoff before the context is full, not after. Try it by hand once and see whether the new session picks up cleanly.

Watch  VERDICT

Smart idea with honest limits. It fails if the early-access API changes under it, and it is untested at 600K.

A 164 ms bouncer for your agent's permissions 🚦

TypeSafe's Jev decides which tool calls go through
SCENE

In auto mode, Claude Code asks a classifier whether each tool call is okay. Madison Rickert put TypeSafe's Jev model in front of it. Per the README: allow when Jev is at least 85% sure the call serves your request and every risk check is 25% or lower. Deny when it is risky and unrequested. Anything else goes to the built-in classifier.

THE THING

madisonrickert/jev-permission-gate. The author's numbers, not ours: median permission wait 329 ms down to 164 ms where Jev decides, about half of calls, and zero unsafe allows across 93 labeled cases (35 risky). Commands like sudo, recursive rm and git push never reach Jev.

✂️ STEAL IT

Read the Privacy section before anything else. Each judged call sends your last three messages, the pending command and your project path to TypeSafe's API. That is a real trade for 165 ms.

Watch  VERDICT

The testing is more careful than most 1-day-old repos. It fails if you can't send prompts to a third party, and 93 cases is a small set.

Claude Code's terminal UI, rewritten in Rust 🦀

a drop-in replacement for the Node and Ink interface
SCENE

A developer posted "Claude Code is now in Rust!" on X today and got 86 likes. The post is quiet, the repo is not: srothgan's claude-code-rust has 234 stars, was created in February and was pushed to this morning. It replaces the stock Node and React Ink terminal UI with a native Rust binary built on Ratatui.

THE THING

srothgan/claude-code-rust, Apache-2.0. Per the README it connects to the same Claude API through a local Agent SDK bridge and still needs the claude CLI on your PATH. It lists streaming chat, tool calls, permissions, diffs, MCP and subagents. The install is a curl-to-shell script, so read it first.

✂️ STEAL IT

Run it next to the stock UI on a scratch repo and watch one thing: does a long session feel faster?

Watch  VERDICT

Interesting if your terminal UI lags. It fails if you need a feature the SDK does not support yet, and we have not run it.
