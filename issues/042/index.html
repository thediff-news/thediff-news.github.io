🚨 Anthropic went down twice in a day - and some scheduled runs never happened

Two resolved Friday incidents hit claude.ai, the API, Claude Code, connectors and Managed Agents; a third, affecting purchases, was still recovering Saturday morning. All times and quotes from Anthropic’s own status page.
SCENE

Picture the developer who wired a claude.ai routine to triage the night’s bug reports before standup. Friday morning, standup comes, and the triage simply does not exist - no error, no retry, no output. Anthropic’s own words, in the 15:33 UTC update: "Scheduled tasks and routines can run more than two hours late and some runs have been skipped, and Claude Security scans, reviews and project setup remain delayed."

THE THING

The verified timeline, all from status.claude.com. Incident one, 09:58-11:58 UTC: users could not authenticate to claude.ai and Claude Code; a fix deployed at 11:05, resolved 11:58 - claude.ai and Claude Cowork affected. Incident two, 13:09-15:38 UTC, broader: claude.ai plus mobile apps, the Claude API, Claude Code, connectors including Docs and Sheets, Claude Managed Agents, Claude in Meetings and Claude Security; new connectors were temporarily unavailable during recovery. Incident three opened Saturday 02:54 UTC: elevated errors on purchases, plan upgrades and cancellations; at 03:09 UTC Anthropic moved to Monitoring, warning that some recent payers "may need to wait up to an hour for their plan to update. There is no need to pay again." Separately, the Microsoft 365 connector outage that began Thursday was a Microsoft service incident, per Anthropic’s status text; Anthropic marked its side resolved at 16:40 UTC Friday while noting Microsoft is still completing recovery. Anthropic has stated no cause for the Friday incidents.

✂️ STEAL IT

Steal the operational habit: a cloud agent that runs on a schedule is only as reliable as the provider’s worst day, and yesterday was one. After any provider incident, check the run history yourself - Anthropic said runs were skipped and nowhere promised they would be retried. And write routines to be idempotent, so re-running one by hand after an outage is boring instead of dangerous.

Watch  VERDICT

Nothing to patch in your code today. If you depend on claude.ai scheduled tasks, routines, or Security scans, assume Friday’s runs need verifying by hand. Watch for a post-mortem: three incident banners in roughly 19 hours, the day after Code Mode shipped, is timing Anthropic will be asked about - but timing is all it is until Anthropic says more.

02  Perplexity blog + Hugging Face model card, Nov 12 · HN 107 points at 06:27 IST

🔀 Perplexity publishes how it trains Decider v1.3 - a model that decides instead of generates

Decider v1.3 and a distilled Flash variant read text, JSON or images and return typed, probabilistic answers; a new Locate feature extracts verbatim spans with character offsets and confidence scores. Built on Qwen3.8-27B.
SCENE

The model card’s own example is a support queue: a customer writes "My integration keeps failing with a 401 since we rotated our API key." One call returns three typed answers at once - team: support, urgent: true, frustration: mildly annoyed - no generation, no parsing, no prompt. That is the whole pitch: routing and triage are classification problems, so Perplexity built a classifier and now publishes how it trains and evaluates it.

THE THING

The facts, all from Perplexity’s own materials. Decider v1.3 is a multimodal classification model on a Qwen3.8-27B base, succeeding v1, v1.1, v1.2 and Flash v1.2; Flash v1.3 is distilled from it. It takes a state (text, JSON, or images) plus questions of three types - choice, noul, and score - and returns typed answers. New in v1.3: Locate, which extracts verbatim text spans from the state with character offsets and confidence scores, which is what an audit trail for automated triage needs. Self-hosting wants a CUDA GPU with about 49 GiB for BF16 weights plus working memory - and the Hugging Face repository is private, gated behind an access token, which directly contradicts the "open-weight" framing in some third-party coverage. For everyone else, OpenRouter lists a free tier. This is the second decision-model release in a week, after Google’s Gemini Decision 1 - which scored 66 on Artificial Analysis’ Decision Index in yesterday’s issue; Decider is not on that index yet.

✂️ STEAL IT

Steal the pattern for your own queues: anywhere you route, tag or score with a prompt today, a decision model gives you typed outputs with probabilities instead of prose to parse. The three question types cover most triage logic, and Locate’s character offsets mean every automated decision can cite its evidence span - build that citation habit now, before your queue is too big to audit by hand.

Try today  VERDICT

Decider is on OpenRouter’s free tier, so pointing one real triage queue at it costs an afternoon, not a budget. It fails you if you need self-hosting this week: the weights sit behind HF access approval and want serious VRAM, and there is no independent benchmark of it yet - Perplexity’s evals are Perplexity’s.
