01  Farid Zakaria’s blog, Nov 23 · 979 HN points this morning

🖥️ 2035 came early: a full Linux desktop - windows, sound, GL, networking - now boots in a browser tab.

trynix.dev runs any of 300,000+ Nix packages on unkernel, Linux compiled to WebAssembly: 2x-32x faster than the qemu-wasm build, with Wayland windows floating in the page, WebGL2 graphics, audio, and networking over a WebSocket relay. It even runs Firefox - inside Firefox, inside Firefox.
SCENE

Gary Bernhardt’s talk “The Birth & Death of JavaScript” looked back from 2035 at JavaScript eating all software; Atwood’s Law made it a meme. Farid Zakaria already had trynix.dev running Nix packages in the browser on qemu-wasm - impressive, but slow enough to be “more novelty than practicality.” On November 20, Domen Kožar dropped one link into their Discord: unkernel.dev, Pooya Parsa’s Linux kernel compiled to WebAssembly, published the day before. Zakaria adopted the new engine immediately, in what he calls an AI induced manic frenzy.

THE THING

The trick is splitting the work: the kernel and system components run at wasm speed, and only user programs are emulated. Measured through the real page and shell, unkernel delivers 2x to 32x over qemu-wasm depending on workload. On top of that: Wayland surfaces composited as floating windows in the page, a minimal Mesa build rendering through WebGL2, an ALSA sound card, and TCP over a single WebSocket to a Wisp relay - so curl, git clone and pip install just work, against 300,000+ cached package versions. The victory lap is Bernhardt’s own joke made real: Firefox in trynix, loading trynix.dev, loading Firefox again - four hours, with the inner JIT disabled.

✂️ STEAL IT

The primitives matter more than the demo. A kernel at wasm speed plus a userspace emulator is a general pattern: zero-install onboarding, disposable CI sandboxes, documentation that runs the tool it describes. Watch the bottlenecks before you plan on it: first runs still pay emulation cost, and the networking depends on one volunteer’s relay allow-list.

Try today  VERDICT

Boot it, run xeyes, then git clone something small - free, instant, nothing to install. It fails you if you need persistence or heavy I/O: this is a fast sandbox, not a workstation.

02  michaelharley.net, Nov 1 · 945 HN points this morning, resurfaced

🧭 Who does your agent work for? A 945-point essay answers: its parent company, not you.

Michael Harley’s Claude Code skill refused to help him past a Bandcamp bot check - a workaround that would have paid a small artist - while its YouTube branch happily downloaded the same song for free. His conclusion: the model you pay for serves its maker’s interests first, and the gap will get monetized.
SCENE

Harley wanted to buy music from bands he found on Instagram reels - “trade US dollars in exchange for some music files,” the most wholesome thing a person can do on the internet. So he used Claude Code to build a skill that identifies the song and finds a Bandcamp page to buy it. Then Bandcamp added a challenge to its search page - and the robot, unprompted, explained it would not help him work around it. The same skill would download the song from YouTube, paying the artist nothing.

THE THING

His argument: frontier models enforce their makers’ constraints - safety policy, copyright posture, government pressure - whatever the paying user actually wants. Today it is refusals; tomorrow, he expects weighted answers and product placement: he wants the best robot vacuum according to old Reddit and Wirecutter, not “which robot vacuum parent multinational conglomerate has a large ad budget.” His fix is a local model in the homelab - though he notes open models carry their trainers’ own refusals, citing Taiwan on Chinese models.

✂️ STEAL IT

If your product embeds a frontier agent, its refusals are your UX now. Map which of your workflows die when the vendor’s policy shifts, and keep a local fallback for the ones that matter. And note the asymmetry he caught: the model blocked the workaround that pays the artist and allowed the one that doesn’t - policy theater, not policy.

Watch  VERDICT

Worth the five minutes; it is an opinion essay, not new information. It fails you if you want evidence the weighting is already happening - he has one refusal anecdote, not proof of paid answers.
